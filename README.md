# 천년가족 · 브라우저 에디션

브라우저에서 즐기는 천년가족 v50입니다.

- 집 화면에서만 두 손가락으로 확대·축소합니다. 따라가기를 누르면 기본 배율로 돌아옵니다.
- 배속 버튼: 1배 → 6.5배 → 13배 → 1배.
- 복원한 사건의 이름 표시를 수정했고, 큰 터치 버튼을 화면 중앙에 배치했습니다.

게임은 각자 사용하는 브라우저에 저장되며, 별도 로그인이나 저장 서버는 필요하지 않습니다.

GitHub Pages에서 `index.html`을 열면 바로 시작할 수 있습니다.

부재중 가족의 역사는 사건 제목·인물 이름·다시보기만 간결하게 표시합니다. 원작 사건 색상과 다시보기 소리를 반영했습니다.

한부모로 시작하는 가족의 자동 자녀 외형 유전을 수정했습니다. 직접 지정한 외형과 기존 저장 가족은 유지됩니다.
