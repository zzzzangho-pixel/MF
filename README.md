부재중 가족의 역사는 사건 제목·인물 이름·날짜·다시보기를 간결하게 표시합니다. 원작 사건 색상과 다시보기 소리를 반영했습니다.

한부모로 시작하는 가족의 자동 자녀 외형 유전을 수정했습니다. 직접 지정한 외형과 기존 저장 가족은 유지됩니다.

화살·아이템 보관함에 굵은 이름과 작은 설명을 표시합니다. 인물 이야기의 스킬 이름을 누르면 설명과 효과를 작은 플로팅 창에서 볼 수 있습니다.

집 화면을 축소해 볼 때 원본 도트가 먼저 뭉개지지 않도록 표시 해상도를 높였습니다. 기본 배율·사건 장면·원래 그림·저장 데이터는 유지합니다.

타이틀 캐릭터와 큐피트를 더 선명하게 표시하고, 사건·기록·가족 역사의 실제 외형과 이름 복원 및 감정 효과 표시와 원작 성별별 특수 의상·색상 처리를 개선합니다. 원래 배경·도트·크기·게임 규칙과 저장은 유지합니다.

부재중 처리 저장을 무손실 압축해 기록·가족·백업을 그대로 보존하며 저장 한도 문제를 완화하고, 완료된 부재중 기록을 일반 이벤트보다 먼저 표시합니다. 기존 JSON 저장을 그대로 불러올 수 있습니다.

부재중 역사 목록의 인물 이름 옆에 사건 당시 게임 날짜를 YYMMDD 형식으로 표시합니다. 날짜가 없는 이전 기록은 —로 표시하며 날짜를 추정하지 않습니다.

큐피트 메뉴의 가족의 역사 화면에서만 큐피트 그림을 숨기고 목록을 전체 너비로 표시합니다. 목록의 장면 복원 등 안내 배지를 없애고 한 페이지를 3개에서 6개 기록으로 늘렸습니다. 다른 메뉴·실제 다시보기·저장·기존 YYMMDD 날짜 표시는 유지합니다.

옛 가족 기록과 다시보기에서 한국어 별칭이 남아 있지 않은 계보 인물·배우자·임시 애인의 원작 자동 이름을 한국어 기본 이름으로 표시합니다. 저장된 이름과 직접 입력한 이름을 우선 유지하며, 확인된 인물 정보만 사용합니다. 실제 가족 이름·저장·난수를 새로 만들거나 다른 일본어 문장을 일괄 치환하지 않습니다. 기존 기록·원작 규칙·그림·소리와 가족 역사 화면의 날짜·한 페이지 6개 표시는 유지합니다.

선택한 가족의 이름 옆에 현재 적용 중인 힘내라·진정해 화살 상태와 화살 효과 기간을 간단히 표시합니다. 실제 원작 효과 상태를 읽어 보여주며, 화살 규칙·시간 진행·가족 기록·저장 형식은 바꾸지 않습니다.

화살 상태 배지를 자세히 버튼에서 떨어뜨려 캐릭터 정보 쪽에 정렬하고, 화살 종류에 어울리는 배경색으로 구분합니다. 실제 화살 효과·기간·게임 진행·저장 형식은 바꾸지 않습니다.

메인 가족 카드에서 좌우 터치 슬라이드로 이전·다음 가족을 선택할 수 있습니다. 기존 화살표·자세히 버튼과 세로 스크롤은 유지하며, 게임 진행·화살 효과·저장 형식은 바꾸지 않습니다.

# 천년가족 웹판 v63

- 원작 부재중 기록의 날짜3바이트와 대상선택1바이트를 분리해 해석합니다. 저장된 원본 선택값으로 실제 기록 인물·당시 나이·날짜를 복원하며, 기존 기록 키·저장된 옛 날짜 값은 손대지 않습니다. 새 기록에는 선택 메타데이터를 명시 보존합니다. 익명 대체 인물은 사용하지 않습니다.
- 원작 아이템12종 사용 결과 대사·색상·대상 표시와 원작효과음215/20틱창전환을 연결합니다. 실제 사용·차감은 기존원작호출1회, 별도 파티클이라고 주장하지 않습니다. 웹 저장 안내만 현재UI에 맞춥니다.
- 관심사 설명은 해당 인물의 미읽은 사건을 끝까지 읽은 뒤 갱신합니다. 사전연출·연속사건·저장재접속 중에는 결과를 미리 공개하지 않습니다. 원작 효과 적용 시점은 바꾸지 않습니다.
- 집 왼쪽 아래50–200% 줌슬라이더. 선택·따라가기·핀치·사건복귀·저장재접속 시 배율유지, 원작사건화면은1배그대로입니다.

- 가족 역사 인물 탭에 좌우 화살표와 끝 표시를 추가하고, 인물 선택·쪽 이동·다시보기 복귀 시 가로 위치를 유지합니다.
- 메인 인물 카드의 관심사 칸을 내용 높이에 맞추고, 하트 아래에 보유 스킬과 기존 상세 화면과 같은 능력치 등급을 표시합니다.

기존 원작 규칙·그림·음원·저장·이름·게임RNG를 보존합니다. 실제폰/사용자실저장/전체캠페인검증을 뜻하지 않습니다. 반려동물v11은별도 로컬시험판으로, 이번공개판에는포함하지않습니다.

반려동물을 가족카드에서 입양하고 돌볼 수 있습니다. 입양·산책·놀이·질병·치료·이별 장면, 기존 저장과 호환되는 반려동물 상태 저장, 원본 크기의 감정 말풍선을 추가했습니다. 기존 v63 여섯 가지 개선을 유지하며, 음수 살림 표시와 장기 부재중 날짜 처리 오류를 수정했습니다.

가족 카드가 화면의 남은 세로 공간을 채우고, 카드의 스킬을 눌러 기존 자세히 화면과 같은 설명을 볼 수 있습니다. 집 화면 확대는 멀리·보통·확대 세 단계로 저장됩니다. 반려동물은 가족이 게임 안에서 자연스럽게 맞이하고 온 가족이 함께 돌보며, 메뉴는 상태·소식·기록만 보여줍니다. 반려동물 중심 사건은 원작 예고·전환·캐릭터 움직임과 실제 원작 효과음·배경음으로 이어집니다. 기존 저장과 원작 규칙은 유지합니다.

v66: 가족 카드의 안쪽 설명칸은 내용 높이를 유지하고, 바깥 카드 배경만 화면의 남는 높이에 맞춥니다. 초상·이름·스킬·능력·활동·설명·몰입도를 한 묶음으로 세로 중앙에 배치합니다. 게임 진행과 저장 데이터는 변경하지 않습니다.

v67: 시작 준비 화면에 실제 다운로드 진행 바·퍼센트·받은 용량을 표시합니다. 다운로드 이후 파일 확인과 게임 준비를 구분해 안내하고, 연결 오류 시 다시 시도할 수 있습니다. 가족 카드 수정과 게임·저장 데이터는 그대로 유지합니다.

v68: 메인 화면에서 매 프레임 반복하던 가족·옛 기록 전체 복사를 없애고, 대사를 넘길 때 이전 저장본을 다시 압축하지 않도록 개선했습니다. 자동 저장과 백업·원작 사건 우선순위·반려동물 연출·게임 속도는 그대로 유지합니다. 시작 화면의 실제 다운로드 진행 바와 가족 카드 배경 조절도 유지합니다.

v70: 확대 조절을 세로·반투명으로 바꾸고 시작 문구를 로딩 중으로 통일했습니다. 매 프레임 반려동물 표시층을 숨겼다 다시 켜던 처리를 없애고, 사건 전환 시 검증된 같은 자동 저장을 재검사하지 않도록 개선했습니다. 자동 저장은 계속 즉시 동기 저장하며, 수동 저장·기존 파일 읽기·백업·게임 속도와 연출은 유지합니다.

정사각형에 가까운 화면과 가로 화면에서는 게임·조작 버튼을 왼쪽, 가족 정보를 오른쪽에 배치합니다. 화면을 세로로 돌리면 기존 세로 UI가 그대로 돌아옵니다. 짧은 가로 화면에서도 모든 메뉴와 가족 넘기기를 사용할 수 있으며, 긴 가족 설명은 정보 영역 안에서 스크롤해 읽을 수 있습니다. 게임 진행·저장·원작 그래픽은 그대로 유지됩니다.

# v72 — 가로 화면 슬라이드 탭

정사각형·가로 화면에서는 게임 화면을 넓게 쓰고, 오른쪽 ‘가족’ 탭을 누르면 캐릭터 정보가, 아래 ‘메뉴’ 탭을 누르면 화살·아이템·가족·큐피트·종료 버튼이 부드럽게 나옵니다. 패널 바깥이나 닫기를 누르면 다시 접힙니다. 세로 UI와 저장 방식은 유지합니다.

기존 앱은 재설치 없이 저장 후 완전히 닫았다 다시 열면 적용됩니다.

v73 수정: 부재중 진행을 마친 뒤 첫 날짜의 사건 처리가 누락되지 않도록 했습니다. 이미 실행을 마친 기한 지난 개인 예약 사건은 해당 예약만 정확히 정리하여 같은 이별 사건이 매일 반복되는 문제를 수정했습니다. 기존 가족·저장·미래 예약·기록은 유지합니다.

부재중에 실제 발생한 연애·이별 사건이 원작 메모 정리 과정에서 사라지는 문제를 수정했습니다. 발생 시점의 날짜·인물·상대 정보를 별도로 보존해 가족의 역사와 다시보기, 저장 후 재실행에서도 유지합니다. 원작의 연애 규칙·사건 결과·난수는 변경하지 않습니다. 이미 정보가 사라진 과거의 이별 날짜나 사건은 추측해서 추가하지 않습니다. v73의 반복 이별·부재중 종료 날짜 수정도 유지합니다. 부재중 기록과 가족의 역사에 전체/중요한 사건만 전환을 추가했습니다. 원작의 중요 사건 표시를 기준으로 화면만 필터링하며 원본 기록은 유지합니다.

가족 정보가 옆으로 접히는 가로 UI에서만 선택한 가족의 이름·실제 하트·현재 활동 제목을 게임 화면 아래 반투명 창으로 표시합니다. 캐릭터 이미지는 넣지 않고 좌우 버튼으로 가족을 바꿉니다. 세로 화면은 기존 배치를 유지합니다. 원작 사건·대사·주요 창을 가리지 않으며 게임 규칙·난수·사건·저장 방식과 v74의 기록 보존·중요 사건 필터는 그대로입니다.
